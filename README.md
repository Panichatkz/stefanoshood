# Stefano's Hood ☕

A lightweight, modular social media web application built with PHP, PDO, MySQL, jQuery Mobile, and interactive React.js components. Designed for small organizations and close-knit communities.

## Features
- **Secure Authentication:** User signup with real-time AJAX username availability checks and PDO prepared database security.
- **Profiles & Avatars:** Custom user bios with automated image resizing, compression, and edge enhancement.
- **Social Graph:** Follow members, maintain mutual friend networks, and view network updates.
- **Messaging:** Public posts and private "whisper" messaging system.
- **Interactive UI:** Mobile-optimized layout enhanced with React.js components.

---

## Prerequisites
- PHP >= 8.1 with PDO MySQL extension
- Composer
- Node.js & npm
- Nginx & MySQL Server
